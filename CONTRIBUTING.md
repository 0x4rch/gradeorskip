# Contributing

Bug reports and pull requests are welcome.

- Run `make test` before opening a pull request. Add a test when you change centering, grading or ROI math.
- Keep the product honest. Grades stay ranges, prices are never invented, and anything unverified says so.
- Don't commit real card photos or scans. Card art is copyrighted, so tests use `tests/fixtures/synthetic`.
- Don't add code that gets around a site's bot protection or terms.

Labelled pre-submission photos with real PSA results are the most useful thing you can share: see "Calibration" in the README, and open an issue before sending images.
